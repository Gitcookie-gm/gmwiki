创世传说
原初世界被神之战撕裂。高位神明珐埃尔为庇护追随者，以残存神力撕开空间裂口，创造恩格海姆，随后陷入永眠。
随行之神霍普斯因恐惧原初战场，伪装成人类潜伏至今。规则碎片散落于世，化为万千契约。
大静默（创世纪80–150年）抹去了历史，仅远古遗民以口传延续真相。

结界与光幕
光幕是横贯天际的五色极光，恩格海姆唯一真实天象——实为珐埃尔结界的本体。
光幕之夜夜如白昼，持续数日。民众视作神恩显现，实则结界神力波动，新的契约碎片于此显现。
无人知晓结界的存在，更无人知晓——珐埃尔苏醒之日，便是结界破碎之时。

影组织
恩格海姆最神秘、最凶残的非法组织。没有人知道它的真面目，甚至不知道"影"是否真的存在——它更像一个游荡在谣言与尸体之间的名字。
结构：松散而致命，成员互不认识，通过暗语和铁质标记物联络。
表层：执行者（猎杀、收集、传递信息）
中层：联络者（接收指令、分配任务）
深层：真正的使徒（极少现身）
已知成员：朽刃（格鲁恩组长）、绣口（奥兰巴托情报员）、一针（追踪易容）
※ 真实首领为霍普斯，借影组织猎杀高阶执契者，压制珐埃尔力量恢复。

光幕教派
信仰：光幕之神（实为珐埃尔，不知真名）
国教：奥兰巴托 · 教皇：霍普斯
核心教义："神以光幕启示世人，我等当以仪式回应。"
注重公开仪式与集体礼拜，强调秩序与等级。组织结构：教徒→司祭→执事→主教→教皇。
圣仪：光幕祷词——光幕之夜，信徒列队走入光幕广场，手持权杖唱诗到天明。
表面宣扬光幕启示，内里……

秩序圣堂
信仰：秩序之父（实为珐埃尔，不知真名）
国教：格鲁恩 · 教皇：奥古斯都
核心教义："被遗忘的神明沉默不语，被遗忘的战场终将重新开启。"
行事隐秘，教义不公开。掌握原初魔法——来自原初世界"旧人类"时代的凡人魔法符文，可大幅强化契约效果。
圣仪：骨书——每三年一次"骨书重写"，将历史以符文篆刻在骨片上。
圣物："沉默之刃"——无柄短剑，不杀生，但"让不应存在的事停止存在"。
※ 他们是"记得真相的人"——知道恩格海姆是庇护所，也知结界中潜伏着低位神明。

教派间关系
光幕教派 vs 秩序圣堂：
表面为正神教派与异端之争，实质为"维护庇护所"与"真相传承者"之间的深层对立。
两大教派均不知珐埃尔真名，这是一个共同的秘密。
秩序圣堂试图积累契约材料打破结界返回原初世界，却不知霍普斯早已是光幕教皇，甚至可能已被其暗中引导。

执契武装
制造者：普通人之中的武装工匠。
原理：执契者死后掉落无主契约，工匠收集后用于装备"结契"，使装备产生异能。
风险：结契越多，能量负重越大，可能异变乃至死亡。
限制：并非所有装备都能承受契约力量，无法支撑时装备与契约一并消散。

异界者
被珐埃尔的残响感召拉入恩格海姆的异界灵魂，在灵廊中苏醒，保留穿越前完整记忆。
触碰契约符号即成为7阶执契者。死亡后扣除经验值，灵魂回灵廊，找到对应门后返回。
叙事定位：故事的核心视角角色，灵廊与契约规则之间唯一的钥匙。

// 渲染契约
function renderContracts() {
const grid = document.getElementById('contractGrid');
if (!grid) return;
grid.innerHTML = '';
const levels = ['7阶','6阶','5阶','4阶','3阶','2阶','1阶','0阶'];
contractData.forEach(c => {
const card = document.createElement('div');
card.className = 'card';
let rows = '';
c.levels.forEach((desc, i) => {
const isZero = i === 7;
rows += `${levels[i]}${desc}`;
});
card.innerHTML = `${c.name} ${c.cat||''}${rows}`;
grid.appendChild(card);
});
}

// 渲染魔物
function renderCreatures() {
const container = document.getElementById('creatureRegions');
if (!container) return;
container.innerHTML = '';
const order = ['珂莱迪亚','奥兰巴托','格鲁恩','阿拉纳','跨区域'];
order.forEach(region => {
const data = creatureRegions[region];
if (!data) return;
const total = (data.low?.length||0)+(data.mid?.length||0)+(data.high?.length||0);
if (total===0) return;
const sec = document.createElement('div');
sec.className = 'region-section';
const parts = [];
if (data.low?.length) parts.push(`低${data.low.length}`);
if (data.mid?.length) parts.push(`中${data.mid.length}`);
if (data.high?.length) parts.push(`高${data.high.length}`);
const badge = region==='跨区域' ? '四国共有' : parts.join(' · ');
sec.innerHTML = `${region}${badge} ${total}`;
['low','mid','high'].forEach(tier => {
const list = data[tier];
if (!list || list.length===0) return;
const tierName = {low:'低阶',mid:'中阶',high:'高阶'}[tier];
const cls = tier;
const tags = list.map(n => `${n}`).join('');
const group = document.createElement('div');
group.innerHTML = `${tierName} ${tags}`;
sec.appendChild(group);
});
container.appendChild(sec);
});
}

// Tab切换
function initTabs() {
const btns = document.querySelectorAll('.tab-btn');
const panels = document.querySelectorAll('.tab-panel');
btns.forEach(b => {
b.addEventListener('click', () => {
const target = b.dataset.tab;
btns.forEach(x => x.classList.remove('active'));
b.classList.add('active');
panels.forEach(p => p.classList.remove('active'));
const panel = document.getElementById('tab-' + target);
if (panel) panel.classList.add('active');
});
});
}

document.addEventListener('DOMContentLoaded', () => {
renderContracts();
renderCreatures();
initTabs();
});
