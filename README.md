## 部署到 GitHub Pages
1. 新建一个 GitHub 仓库（如 `under-the-veil-wiki`）。
2. 把本文件夹内**所有文件**（含 `index.html`、各 `*.html`、`assets/`、`.nojekyll`）上传到仓库。
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
4. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 提示：也可把本文件夹命名为 `docs/` 放进仓库，然后 Pages 目录选 `/docs`。
